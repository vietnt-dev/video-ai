# Thêm nhạc nền không bản quyền

Đặt file nhạc nền vào thư mục `backend/assets/music/`.

## Nguồn nhạc miễn phí:

1. **YouTube Audio Library**: https://studio.youtube.com/channel/music
2. **Pixabay Music**: https://pixabay.com/music/
3. **Free Music Archive**: https://freemusicarchive.org/
4. **Bensound**: https://www.bensound.com/

## Định dạng hỗ trợ:
- MP3 (khuyến nghị)
- WAV
- OGG

## Lưu ý:
- Hệ thống sẽ tự động loop nhạc nếu ngắn hơn video
- Volume nhạc nền được set ở 15% để không lấn át giọng đọc
- Đặt nhiều file nhạc, hệ thống sẽ chọn ngẫu nhiên (cần update code)
